# Python Calculator

A simple and efficient command-line calculator built with Python. This project performs essential arithmetic operations using user input and demonstrates the fundamentals of Python programming.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Floor Division
- Modulus
- Exponentiation (Power)
- Percentage Calculation
- Division by Zero Handling
- Clean Command-Line Interface

## Technologies Used
- Python 3

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/python-calculator.git
```

Run the project:

```bash
python calculator.py
```
